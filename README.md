# FitAI Backend

FastAPI backend for the FitAI Gym application.

## Features
- User Authentication (JWT)
- Onboarding & Profile Management
- AI Trainer Integration
- Nutrition Path Analysis
- MongoDB Integration

## Setup
1. Create a virtual environment: `python -m venv venv`
2. Activate it: `.\venv\Scripts\activate` (Windows)
3. Install dependencies: `pip install -r requirements.txt` (Make sure to create/update requirements.txt)
4. Run the server: `python main.py`
